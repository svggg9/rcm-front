# Первый этап мобильной покупательской версии

Дата проверки: 7 сентября 2026. Код: `/Users/admin/IdeaProjects/front/rcm-front`.

Внедрено локально: покупательская нижняя навигация на основных разделах; компактная мобильная шапка; product-first каталог с выбором категории снизу, фильтрами и реальной дозагрузкой; компактные действия корзины; редактируемые свёрнутые секции доставки и получателя; закреплённые итоговые панели; лёгкий SVG-рубль в тёмном золоте ДС. Мобильные правила ограничены шириной 640 px. Кабинет продавца и его существующие изменения не редактировались.

## Проверки

- `npm run build`, `npm run lint`, `npx tsc --noEmit`, `git diff --check` — успешно.
- Headless Chrome / Playwright: 320 и 390 px, контроль desktop 1280 px.
- Каталог: реальные публичные товары; 48 → 54, повтор после имитированной ошибки, сохранение при Back, сброс после смены категории, применение аудитории, Escape/focus/body lock, отсутствие горизонтального переполнения и JS-ошибок.
- Корзина / оформление: синтетические данные и перехваченные API; действия 44 px, edit/done, формат телефона, раскрытие валидации, состояние до расчёта доставки и после расчёта. Заказы и платежи не отправлялись.
- Временная тестовая страница оформления удалена до финальной сборки.
- Предупреждения сборки только об устаревших справочниках браузеров; зависимости не обновлялись.

## Изображения

`catalog-*`, `categories-*`, `filters-*` показывают публичный локальный каталог. `cart-*` и `checkout-*` используют тестовые имена, адреса, цены и изображения-заглушки, это не клиентские данные. Индикатор инструментов разработки скрыт только при снятии скриншотов.

## Границы этапа

Изменения не опубликованы и не закоммичены. Полный редизайн карточки товара, кабинета покупателя и мобильного кабинета продавца не входит в этот этап. Проверка на физическом iPhone/Android остаётся перед выпуском.

В небольшом каталоге доступные категории определяются по полному снимку до 96 товаров; при большем ассортименте или ошибке запроса используется полный справочник. Дозагрузка сохраняется в памяти вкладки (до 6 наборов фильтров); полная перезагрузка открывает серверную страницу из URL.
