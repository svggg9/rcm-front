# RCM — action icons v1

Набор для обсуждения мобильного интерфейса. Приложение не изменено.

Восемь отдельных векторных SVG: `trash-2`, `pencil`, `minus`, `plus`, `chevron-right`, `chevron-left`, `heart`, `x`.

Геометрия скопирована без изменений из установленного `lucide-react` **1.24.0**, файлов `dist/esm/icons/<name>.mjs` проекта `/Users/admin/IdeaProjects/front/rcm-front`. Атрибут React `key` не включён: он не относится к геометрии SVG. `stroke-width` приведён к существующему стилю RCM — **1.8**. Набор использует `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`, круглые окончания и соединения линий Lucide.

## Применение

- Видимый размер иконки: **18–20 px** для действий в карточке товара, корзине и оформлении.
- Область нажатия кнопки: **минимум 44 × 44 px**, независимо от визуального размера иконки. Соседние области не перекрываются.
- `trash-2`: удалить товар из корзины.
- `pencil`: изменить получателя, адрес или другой уже заполненный блок.
- `minus` / `plus`: уменьшить / увеличить количество.
- `chevron-right`: открыть следующий уровень или выбрать значение; это не синоним редактирования.
- `chevron-left`: вернуться назад.
- `heart`: добавить в избранное; кнопке с переключаемым состоянием нужен `aria-pressed`.
- `x`: закрыть окно или панель. Для удаления товара используется `trash-2`.

Для кнопки без видимого текста обязателен понятный `aria-label`, например `aria-label="Удалить куртку из корзины"` или `aria-label="Изменить получателя"`. Встроенный SVG скрыт от скринридера (`aria-hidden="true"`), поскольку действие озвучивает кнопка. Эти файлы предназначены для inline SVG; при использовании через `<img>` задавайте `alt=""` внутри подписанной кнопки. `currentColor` наследует цвет интерфейса при inline-вставке; SVG через `<img>` не наследует цвет внешней страницы.

Компактный счётчик сохраняет отдельные области нажатия по 44 px у «−» и «+». Уменьшать следует видимую рамку, отступы и размер символов, а не доступность кнопок. Основные действия «К оформлению» и «Перейти к оплате», цены, статусы и подписи нижней навигации остаются текстовыми.
