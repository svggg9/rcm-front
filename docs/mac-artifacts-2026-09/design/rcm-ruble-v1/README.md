# RCM — варианты знака рубля

Три оригинальных векторных эскиза для обсуждения: лёгкий, геометрический, узкий. Это варианты фирменного знака, ещё не утверждённая замена компонента Price.

Во всех файлах цвет `#7A613A` взят из `--gold-deep` существующей дизайн-системы RCM. Тонкий штрих задаётся геометрией SVG, независимо от font-weight цифр. Сохраняются узнаваемые элементы ₽: вертикальная стойка, чаша, две горизонтали.

Для вставки рядом с Inter: начальный ориентир `height: 1em; width: .8em; vertical-align: -.1em`. Размер и оптическую базовую линию следует проверить в реальном компоненте Price при 15, 20 и 28 px. SVG не должен увеличиваться только потому, что цена жирная. В контейнере суммы сохранять `white-space: nowrap`.

У суммы доступное название содержит слово «рублей», а декоративный SVG — `aria-hidden="true"`. При вставке через img использовать `alt=""`; доступное название остаётся на всей сумме.

Предпросмотр меню следует существующему правилу Header: активные текст и иконка чёрные (`#111111`), тонкое подчёркивание `--gold` (`#B08D57`), неактивные — `--muted` (`#6F6F6F`). Оранжевый не используется. Это применение существующих токенов к предлагаемой нижней навигации, не утверждение о наличии такой навигации в текущем коде.

В приложении изменений нет. Полный редизайн и внедрение этих знаков не выполнены.
