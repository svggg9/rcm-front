# рцмаркет — текстовый логотип, поиск v1

Написание, заданное пользователем: **рцмаркет**, строчными русскими буквами.
8 сентября 2026 пользователь выбрал **вариант 03 — Unbounded 500**. Выбранный комплект находится в `../rcmarket-brand-v1/`. Этот каталог сохраняет исходные шесть направлений для истории; на сайт они не внедрялись.

- 01: Yeseva One 400, перевод исходного шрифта в контуры
- 02: Manrope 600, перевод исходного шрифта в контуры
- 03: Unbounded 500, перевод исходного шрифта в контуры
- 04: собственная геометрическая конструкция букв
- 05: собственная угловатая конструкция букв
- 06: собственная конструкция с короткими клиновидными окончаниями

SVG не содержат текстовых элементов, растров или внешних ресурсов. Чёрная и белая версии имеют прозрачный фон. Варианты 04–06 используют векторные штрихи; это редактируемые контуры, не шрифт.
Для каждого варианта предлагается favicon с его буквой «р» на чёрном фоне. В вариантах 04 и 06 тонкие штрихи значка усилены для малого размера. Это также предложение до согласования.

## Комплект

- `svg/`: шесть вариантов, каждый в чёрном и белом
- `favicon/`: SVG, PNG 16/32 и ICO каждого варианта
- `manifest.json`: параметры и соответствия
- `build.py`: воспроизводимая сборка из шрифтов и собственных контуров
- `rasterize.cjs`: PNG/ICO из готовых векторных значков

После выбора: оптическая доводка расстояний и favicon на 16 px, адаптация реальной шапки, затем apple-touch-icon 180 px, PWA 192/512 при необходимости. Полное название нельзя сжимать в favicon. Новое написание не означает переименование технических идентификаторов или домена.
