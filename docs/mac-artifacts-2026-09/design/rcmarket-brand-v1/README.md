# рцмаркет — выбранный текстовый логотип v1

Выбор пользователя от 8 сентября 2026: **вариант 03**, Unbounded 500.

## Зафиксировано

- Написание: **рцмаркет**, только строчные русские буквы, без пробелов
- Основной текстовый логотип: вариант 03 из набора `rcmarket-wordmark-v1`
- Буквы переведены в векторные контуры; шрифт для отображения SVG не нужен
- Favicon: строчная «р» выбранного начертания, белая на чёрном фоне
- Чёрный логотип — на светлой поверхности; белый — на чёрной
- Не растягивать, не наклонять и не менять межбуквенные интервалы внутри готового SVG
- Название файла и технические идентификаторы остаются латиницей

## Файлы

- `wordmark-black.svg`, `wordmark-white.svg` — прозрачный фон, исходные выбранные контуры без изменения начертания
- `favicon.svg` — масштабируемый значок
- `favicon.ico` — 16 и 32 px
- `favicon-16.png`, `favicon-32.png`
- `apple-touch-icon.png` — 180 × 180 px, непрозрачный фон
- `icon-192.png`, `icon-512.png` — запас для Android/PWA, приложение этим не включается
- `OFL-Unbounded.txt` — лицензия исходного шрифта
- `brand.json` — машинно-читаемое соответствие файлов

В SVG нет `<text>`, изображений, скриптов или внешних ресурсов. Логотип имеет пропорции примерно 7,943 : 1. Высота при ширине 224 px — около 28,2 px.

## Предлагаемые правила размещения — требуют проверки в реальном интерфейсе

- Не прижимать логотип к иконкам: отправная точка охранного поля — половина видимой высоты знака
- На desktop примерять ширину 224 px; мобильный размер выбирать вместе с расположением кнопок шапки
- Не использовать полное название как favicon
- Для ссылок, ведущих на главную, доступное имя: «рцмаркет — главная»

## Границы изменения

Этот пакет фиксирует выбор для дизайн-системы. Код frontend/backend не изменялся, логотип и иконки не подключены к сайту, деплоя не было.
Обложка для Telegram/Open Graph — отдельный следующий макет: здесь её нет.
