## Начало работы

- Общайся с пользователем по-русски. Основное рабочее место — Windows; команды запуска документируй для PowerShell, используя относительные пути.
- В начале задачи прочитай README.md, PROJECT_PLAN.md и WINDOWS_HANDOFF.md. Для UI прочитай актуальный верхний раздел DESIGN_SYSTEM.md; для выкладки — DEPLOYMENT_2026-09-19.md.
- Проверь git status и текущую ветку, сохрани существующие пользовательские изменения. Основная ветка этого репозитория — main; backend svggg9/rcm использует master.
- Найди соседний backend по доступным каталогам, не полагайся на /Users/admin/... и не предполагай, что он уже клонирован. Если задача затрагивает API, прочитай его BACKEND_PLAN.md и соответствующий код.
- Текущие инструкции пользователя имеют приоритет над историческими документами. Старые fix/* ветки и архивные планы не сливай и не применяй автоматически.
- Общую очередь веди в FRONTEND_BACKLOG.md по доступным чатам frontend и backend, включая связанные чаты по cwd без projectId и технический архив. При пересмотре плана сверяй последние результаты с текущим кодом; записывай источники, отложенные находки и следующий шаг. Не дублируй уже идущую в другом чате работу; чтение его статуса не разрешает отправку сообщений или повторную выкладку.

## Правила интерфейса

- Раскрытое выпадающее поле и его список образуют единый внешний контур без внутренней разделительной линии и зазора. Правило общее для обычного выбора, поиска, нескольких значений и подсказок; при ошибке контур красный, клавиатурный фокус видим. Используй общие стили ДС и не возвращай разделитель локальными переопределениями.
- Короткие интерфейсные тексты — подписи, плейсхолдеры, подсказки, пояснения у кнопок и краткие подтверждения — пиши без точки в конце, даже если грамматически это полное предложение. Примеры: «От 10 до 5000 символов», «Ответ придёт на вашу электронную почту». Обычная пунктуация нужна в развёрнутых абзацах и пояснениях из нескольких предложений. При работе с другими экранами исправляй такие конечные точки по тому же правилу.
- Сохраняй Inter, чёрный/белый/золото, общие компоненты app/components/ui и токены app/styles.
- У продавца отдельная шапка и два ряда навигации без счётчиков. Верхний раздел «Товары», кнопки добавления возле поиска и фильтров.
- Товар редактируется в правой панели поверх списка; прямой URL остаётся рабочим. Подборка — компактный диалог, мобильный редактор — полноэкранный. Сохраняй предупреждение о несохранённых правках.
- Не возвращай ранние варианты из исторических секций DESIGN_SYSTEM.md. Демонстрационные страницы не являются новым разрешением менять весь интерфейс.
- Не меняй бизнес-статусы/доступные действия только по оформлению UI; сверяй API-контракт. Поиск заказов сейчас работает по загруженной части списка.

- По поручению пользователя 21 октября необходимые локальные перезапуски backend агент выполняет самостоятельно: сохраняй профиль/env, проверяй порт 9696 и не оставляй второй экземпляр.

- Не объявляй полный E2E пройденным по сборке или smoke. В отчёте указывай фактически выполненные проверки.
